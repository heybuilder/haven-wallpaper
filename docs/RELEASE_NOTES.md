# Haven v0.5.0 ? install and get comfortable

Haven now has a Windows installer with bundled Qt and C++ libraries, Start menu shortcuts, and an uninstaller. No Qt download or administrator account is needed.

Click **Enable YouTube imports** once inside the app to download and verify the official optional helpers. Local wallpapers, tasks, goals and clocks work immediately.

Downloads:
- **Haven-Setup-v0.5.0.exe**: recommended installer for Windows x64.
- **Haven-v0.5.0-windows-x64.zip**: portable alternative; extract completely.
- **Haven-v0.5.0-source.zip**: Haven source and installer definition.
- **Haven-v0.5.0-library-sources.zip**: matching dependency sources and build information.
- **SHA256SUMS-v0.5.0.txt**: download checksums.

Uninstalling leaves your personal tasks, settings and imported videos in your local application data folder. No personal content is included in the downloads. This remains an unsigned early release; broader testing on other Windows PCs is needed.
